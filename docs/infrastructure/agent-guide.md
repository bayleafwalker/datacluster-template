## 🏗️ Infrastructure Overview

Cost-optimized Apache Spark platform on Hetzner Cloud (€10/month):
- **Kubernetes**: Talos OS (CX23 control-plane + CX33 worker)
- **Infrastructure**: Terraform with hcloud-talos module
- **Networking**: Cilium CNI, Tailscale VPN on control-plane
- **GitOps**: FluxCD reconciles `infrastructure/`
- **Monitoring**: Prometheus + Grafana
- **Storage**: Hetzner Volumes (CSI) + Object Storage (S3)
- **Secrets**: SOPS-encrypted with age

## 🔑 Key Workflows

### 1. Terraform Operations

**Planning:**
```bash
cd terraform-v2
export SOPS_AGE_KEY_FILE=/projects/dev/datacluster/age.key
sops -d terraform.tfvars.enc > terraform.tfvars
terraform plan -out=upgrade.tfplan
# Review plan carefully
terraform apply upgrade.tfplan
rm terraform.tfvars  # Always cleanup
```

**Applying changes:**
```bash
cd terraform-v2
export SOPS_AGE_KEY_FILE=/projects/dev/datacluster/age.key
sops -d terraform.tfvars.enc > terraform.tfvars
terraform apply
rm terraform.tfvars
```

**Destroying (use with caution):**
```bash
cd terraform-v2
export SOPS_AGE_KEY_FILE=/projects/dev/datacluster/age.key
sops -d terraform.tfvars.enc > terraform.tfvars
terraform destroy
rm terraform.tfvars
```

### 2. Cluster Access

**Standard location:**
```bash
# Set kubeconfig (standard location)
export KUBECONFIG=/projects/dev/datacluster/clusters/.kube/config

# Verify connection
kubectl get nodes

# Talos operations
export TALOSCONFIG=/projects/dev/datacluster/terraform-v2/talosconfig
talosctl -n <PUBLIC_IP> version
```

**Note:** Terraform generates configs to `terraform-v2/` directory, but the standard operational location is `clusters/.kube/config`. Copy fresh configs from Terraform output when needed.

### 3. Talos OS Management

**Generate Talos config:**
```bash
export SOPS_AGE_KEY_FILE=/projects/dev/datacluster/age.key
cd talos
sops -d cluster.yaml > cluster-decrypted.yaml
talhelper genconfig --config cluster-decrypted.yaml
rm cluster-decrypted.yaml
```

**Apply config changes:**
```bash
export TALOSCONFIG=/projects/dev/datacluster/terraform-v2/talosconfig
talosctl apply-config --nodes <NODE_IP> --file clusterconfig/<node>.yaml
```

**Upgrade Talos:**
```bash
export TALOSCONFIG=/projects/dev/datacluster/terraform-v2/talosconfig
talosctl upgrade \
  --nodes <NODE_IP> \
  --image ghcr.io/siderolabs/installer:v1.11.5 \
  --preserve \
  --wait
```

### 4. Flux GitOps

**Check Flux status:**

```bash
flux check

flux get helmreleases -A
```

**Force reconciliation:**

```bash
flux reconcile kustomization infrastructure --with-source
```

### 5. Monitoring Setup

**Edit Grafana dashboards:**

**Add new PrometheusRules:**

## 🚀 Common Infrastructure Tasks

### Add New Node

1. **Update Terraform:**
```hcl
# terraform-v2/main.tf
resource "hcloud_server" "worker_2" {
  name        = "worker-2"
  server_type = "cx33"
  image       = data.hcloud_image.talos.id
  location    = "fsn1"
  # ... rest of config
}
```

2. **Apply Terraform:**
```bash
cd terraform-v2
export SOPS_AGE_KEY_FILE=/projects/dev/datacluster/age.key
sops -d terraform.tfvars.enc > terraform.tfvars
terraform apply
rm terraform.tfvars
```

3. **Update Talos config:**
```bash
# Add worker-2 to talos/cluster.yaml
export SOPS_AGE_KEY_FILE=/projects/dev/datacluster/age.key
sops talos/cluster.yaml
# Add node configuration
```

4. **Bootstrap node:**
```bash
export TALOSCONFIG=/projects/dev/datacluster/terraform-v2/talosconfig
talosctl apply-config --nodes <WORKER_2_IP> --file clusterconfig/worker-2.yaml
```

### Upgrade Kubernetes

1. **Upgrade Talos (includes K8s):**
```bash
export TALOSCONFIG=/projects/dev/datacluster/terraform-v2/talosconfig

# Upgrade control plane first
talosctl upgrade --nodes <CONTROL_PLANE_IP> \
  --image ghcr.io/siderolabs/installer:v1.11.5 \
  --preserve --wait

# Then workers
talosctl upgrade --nodes <WORKER_IP> \
  --image ghcr.io/siderolabs/installer:v1.11.5 \
  --preserve --wait
```

2. **Verify:**
```bash
kubectl get nodes
talosctl version
```

### Update Helm Release

**Edit HelmRelease:**
```yaml
# infrastructure/spark-operator/release.yaml
apiVersion: helm.toolkit.fluxcd.io/v2beta1
kind: HelmRelease
metadata:
  name: spark-operator
  namespace: spark-operator
spec:
  chart:
    spec:
      version: 1.3.0  # Update version
```

**Commit and push:**
```bash
git add infrastructure/spark-operator/release.yaml
git commit -m "chore(spark-operator): upgrade to v1.3.0"
git push
```

Flux will auto-reconcile within minutes.

### Scale Infrastructure

**Update server types in Terraform:**
```hcl
# terraform-v2/main.tf
resource "hcloud_server" "worker_1" {
  name        = "worker-1"
  server_type = "cx53"  # Upgrade from cx33
  # ...
}
```

**Apply:**
```bash
cd terraform-v2
export SOPS_AGE_KEY_FILE=/projects/dev/datacluster/age.key
sops -d terraform.tfvars.enc > terraform.tfvars
terraform apply
rm terraform.tfvars
```

**Note**: This will recreate the server. Plan for downtime or use blue/green deployment.

## 🔐 Security & Encryption

### Encrypting New Files

```bash
export SOPS_AGE_KEY_FILE=/projects/dev/datacluster/age.key

# Encrypt in-place
sops --encrypt --in-place newfile.yaml

# Or encrypt to new file
sops --encrypt input.yaml > input.yaml.enc
```

### Rotating Encryption Keys

1. **Generate new key:**
```bash
age-keygen -o age-new.key
```

2. **Re-encrypt all files with new key:**
```bash
export SOPS_AGE_KEY_FILE_OLD=/projects/dev/datacluster/age.key
export SOPS_AGE_KEY_FILE_NEW=/projects/dev/datacluster/age-new.key

for file in talos/cluster.yaml terraform-v2/terraform.tfvars.enc infrastructure/storage/s3-secret.yaml; do
  sops --rotate --age $(cat age-new.key | grep "public key:" | cut -d: -f2 | xargs) $file
done
```

3. **Update Flux SOPS secret:**
```bash
kubectl create secret generic sops-age \
  --from-file=age.key=age-new.key \
  --namespace=flux-system \
  --dry-run=client -o yaml | kubectl apply -f -
```

4. **Backup old key securely, then replace:**
```bash
mv age.key age-old.key.backup
mv age-new.key age.key
```

### Audit Encrypted Files

```bash
# Check which files are encrypted
find . -type f -name "*.yaml" -exec grep -l "sops:" {} \;

# Verify encryption
for file in talos/cluster.yaml terraform-v2/terraform.tfvars.enc; do
  grep -q "sops:" "$file" && echo "✓ $file is encrypted" || echo "✗ $file is NOT encrypted"
done
```

## 📊 Monitoring & Troubleshooting

### Check Cluster Health

```bash
# Node status
kubectl get nodes -o wide

# System pods
kubectl get pods -n kube-system

# Flux status
flux get all

# Talos health
export TALOSCONFIG=/projects/dev/datacluster/terraform-v2/talosconfig
talosctl health
```

### Access Monitoring UIs

```bash
# Grafana
kubectl port-forward svc/grafana 3000:80 -n monitoring
# Open http://localhost:3000

# Prometheus
kubectl port-forward svc/prometheus 9090:9090 -n monitoring
# Open http://localhost:9090
```

### Common Issues

**Flux not reconciling:**
```bash
# Check Flux logs
flux logs --level=error --all-namespaces

# Force reconcile
flux reconcile kustomization infrastructure --with-source
```

**Talos node unresponsive:**
```bash
# Check node logs
export TALOSCONFIG=/projects/dev/datacluster/terraform-v2/talosconfig
talosctl logs --follow -n <NODE_IP>

# Check service status
talosctl services -n <NODE_IP>
```

**Terraform state locked:**
```bash
# Force unlock (use carefully)
terraform force-unlock <LOCK_ID>
```

## ⚠️ Critical Reminders

1. **Always encrypt secrets** before committing
2. **Always plan Terraform** changes before applying
3. **Test in staging** before production (if available)
4. **Backup age.key** securely offline
5. **Document breaking changes** in commit messages
6. **Use GitOps** - avoid manual kubectl changes to Flux-managed resources
7. **Monitor after changes** - check Grafana/Prometheus for issues
